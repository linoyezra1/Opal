# Opal — בית ליזמות רפואית

פלטפורמת מנויים לשירותי בריאות לצרכנים ישראליים — מחברת בין לקוחות, ארגונים, ספקי שירות, וסוכני מכירות, תחת מנשק ניהול אחד ומלא.

> פותחה עם **Cursor** ו-**Claude** (Anthropic) כעוזרי AI ראשיים לאורך כל תהליך הפיתוח.

## מה המערכת עושה

Opal היא שוק דיגיטלי לשירותי בריאות בישראל. המערכת מאפשרת:

- **לצרכנים** — לגלות, להזמין ולנהל מנויים לשירותי בריאות דרך דפי נחיתה ייחודיים לכל מוצר
- **לארגונים** — להצטרף לחיוב מרכזי חודשי עבור עובדיהם
- **לספקים רפואיים** — להירשם כנותני שירות ולקשר מוצרים לפרופיל שלהם
- **לסוכני מכירות** — לנהל עסקאות ועמלות
- **למנהלי מערכת** — לנהל את כל ממדי הפלטפורמה מדשבורד אחד

## ארכיטקטורה טכנולוגית

### Frontend

| טכנולוגיה | שימוש |
|---|---|
| **React 18** + **Vite 5** | מסגרת UI ובנייה |
| **React Router v6** | ניתוב בצד לקוח |
| **TailwindCSS 3.4** | עיצוב — RTL מלא לעברית |
| **shadcn/ui** (Radix UI) | רכיבי UI נגישים ומבוססי עיצוב |
| **Recharts** | גרפים ודוחות ויזואליים |
| **Lucide React** | ספריית אייקונים |
| **XLSX** | ייצוא נתונים ל-Excel |

### Backend

| טכנולוגיה | שימוש |
|---|---|
| **Node.js** + **Express 5** | שרת API |
| **MongoDB** + **Mongoose** | מסד נתונים ראשי |
| **Nodemailer** | שליחת אימיילים טרנזקציוניים |
| **Google Sheets API** | סנכרון נתונים לגיליונות |
| **Cardcom API** | שער תשלום ישראלי (עיבוד כרטיסי אשראי) |

## מסלולי משתמשים

### 1. צרכן פרטי

```
דף נחיתה (/p/:slug)
  → בחירת מוצר + מילוי פרטים אישיים
  → יצירת מפגש תשלום בCardcom
  → הפניה לסליקה
  → Webhook אישור תשלום → שמירת עסקה ב-MongoDB
  → מילוי טופס מוטבים (/beneficiary-form)
  → שליחת PDF + אימייל אישור
```

### 2. ארגון / חברה

```
הרשמת ארגון (/register)
  → אישור מנהל מערכת
  → יבוא עובדים (/org-employee-register)
  → שליחת אימיילי אישור לעובדים
  → הפעלת עסקאות מרכזיות
  → חיוב חודשי + דוחות
```

### 3. ספק רפואי

```
טופס הצטרפות (/provider-join-request)
  → בדיקת ניהול
  → קישור מוצרים לפרופיל הספק
  → מעקב עמלות וחיובים
```

## דשבורד הניהול

גישה דרך `/admin` עם אימות Bearer Token.

### לוח בקרה ראשי (`/admin/control-panel`)
- **KPIs בזמן אמת**: הכנסות, מנויים פעילים, רווח נקי
- **גרפים חודשיים**: מכירות, ביטולים, ביצועי סוכנים
- **התראות מיידיות**: כישלונות תשלום, עגלות נטושות, חידושים קרובים

### ניהול מוצרים (`/admin/products`)
- יצירה ועריכה של שירותים רפואיים (שם, SKU, תיאור, עלות ספק)
- מאגר קטלוג מוצרים מלא

### בנאי דפי נחיתה (`/admin/product-page-setup`)
- ווייזרד יצירת דפי מוצר עם: כותרות, תמונות, רשימת יתרונות, תמחור
- כל מוצר מקבל slug ייחודי לקישור ישיר

### ניהול מחירונים (`/admin/price-list`)
- יצירת מחירונים מרובי-מוצרים לדפי נחיתה
- קישור מחירון לארגון ספציפי או לקהל כללי
- ארכיב מחירונים ישנים

### דשבורד מנויים (`/admin/subscribers`)
- צפייה בכל העסקאות עם סינון לפי: מוצר, סוכן, טווח תאריכים, סטטוס
- ניהול מצב עסקה: פעיל, ממתין, ביטול ממתין, מבוטל, ארכיב
- ייצוא ל-Excel

### ניהול ארגונים (`/admin/organizations`)
- רשימת כל הארגונים עם: מספר עובדים, פרטי חיוב, היסטוריית תשלומים
- פרופיל ארגון מפורט (`/admin/organizations/:id`): ניהול עובדים, אישור הצטרפות, הגדרות חיוב
- יבוא ארגונים מקבצים

### ניהול ספקים (`/admin/vendors`)
- פרטי קשר, פרטי בנק, מוצרים מקושרים
- ניהול עמלות ספק

### ניהול סוכנים (`/admin/agents`)
- פרטי סוכן (שם, ת"ז, טלפון, חשבון בנק לעמלות)
- מעקב מכירות לפי סוכן

### ניהול ליד ויצירות קשר (`/admin/contacts`)
- לידים נכנסים מדפי נחיתה
- עגלות נטושות לטיפול
- ניהול בקשות ספקים ובקשות הצטרפות

### דוחות (`/admin/reports`)
- **דוח זכאות שירות**: מי זכאי לאיזה שירות ובאיזה תאריך
- **דוח חיוב**: סיכום חיובים לפי ארגון, סוכן, מוצר
- ייצוא ל-Excel עם עיצוב מלא

### ארכיב (`/admin/archive`)
- צפייה בעסקאות מאורכבות
- כללי זכאות לארכיב (לוגיקת `archiveEligibility.js`)

### התראות (`/admin/alerts`)
- התראות בזמן אמת: כישלונות תשלום, ביטולים קרובים, עגלות נטושות

## אינטגרציות חיצוניות

### Cardcom — עיבוד תשלומים
- יצירת מפגש תשלום מאובטח
- קבלת Webhook לאישור עסקה
- ניהול פרופילי חיוב חוזר

### Google Sheets
- סנכרון נתוני מכירות ודוחות לגיליונות Google
- שימוש לדיווח ולשיתוף נתונים עם צוותים

### Nodemailer (SMTP)
- אישור הזמנה ללקוח
- אישור רישום מוטבים עם PDF מצורף
- אימיילי אישור לעובדי ארגון

## לוגיקות עסקיות מרכזיות

### אימות תעודת זהות ישראלית
`utils/israeliId.js` — ולידציה של מספר ת"ז לפי אלגוריתם המשרד הפנים (Luhn-like).

### זכאות שירות
`server/entitlementStatus.js` — בדיקה האם לקוח זכאי לקבל שירות לפי תאריך הפעלה, סטטוס תשלום, ומדיניות המוצר.

### כללי ארכיב
`utils/archiveEligibility.js` — קובע אילו עסקאות ניתנות לארכיב (לפי סטטוס, גיל, ועוד).

### slugify לדפי נחיתה
`utils/stringUtils.js` — המרת שם מוצר לכתובת URL בטוחה (אותיות אנגליות, מספרים, מקף — עד 60 תווים).

### עגלות נטושות
כל כניסה לתהליך הרכישה נשמרת ב-`checkout_drafts`. אם לא הושלמה — נוצרת התראה בדשבורד הניהול.

### חיוב ארגוני חודשי
- HR מייבא עובדים → נוצרות עסקאות ממתינות
- עובדים מאשרים דרך אימייל → עסקאות מופעלות
- בסוף חודש נוצרת חשבונית `monthly_invoices` לארגון

## הרצה מקומית

### דרישות מוקדמות
- Node.js 18+
- MongoDB (מקומי או Atlas)
- חשבון Cardcom לסביבת פיתוח

### התקנה

```bash
# שיבוט המאגר
git clone <repo-url>
cd Opal

# התקנת תלויות
npm install

# הגדרת משתני סביבה
cp .env.example .env
# ערוך את .env עם פרטי הסביבה שלך
```

### משתני סביבה נדרשים (`.env`)

```env
VITE_API_URL=http://localhost:3001
MONGODB_URI=mongodb://localhost:27017/opal
CARDCOM_TERMINAL=...
CARDCOM_USERNAME=...
SMTP_HOST=...
SMTP_USER=...
SMTP_PASS=...
ADMIN_USERNAME=...
ADMIN_PASSWORD=...
JWT_SECRET=...
GOOGLE_SHEETS_ID=...
```

### הרצה

```bash
# פרונטאנד ובאקאנד במקביל
npm run dev:all

# פרונטאנד בלבד
npm run dev

# באקאנד בלבד
npm start
```

## פיתוח עם AI

פרויקט זה פותח תוך שימוש מלא בכלי AI מתקדמים:

### Cursor
סביבת הפיתוח הראשית — עם השלמת קוד מבוססת AI, ניתוח שגיאות בזמן אמת, ויצירת קוד לפי הנחיות בשפה טבעית. שימש לכתיבת רכיבי React, לוגיקות backend, ועיצוב ממשקים.

### Claude (Anthropic)
שימש כיועץ ארכיטקטורה ומפתח AI לאורך כל הפרויקט:
- עיצוב מבנה מסד הנתונים
- כתיבת לוגיקות עסקיות מורכבות (אמות מידה לזכאות, כללי ארכיב, עיבוד תשלומים)
- בניית מנשק ניהול מלא (27 דפים)
- אינטגרציות API (Cardcom, Google Sheets, Nodemailer)
- סקירות קוד, איתור באגים, ואופטימיזציה

> "AI לא החליף את המפתח — הוא הכפיל את יכולתו."
